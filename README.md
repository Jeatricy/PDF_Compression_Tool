# PDF压缩工具

通过把 PDF 每页按指定分辨率渲染成图片、再重新嵌入的方式压缩 PDF 体积，提供图形界面和命令行两种用法，适合扫描件类 PDF 的批量瘦身。

## 功能

- 三种处理模式：**灰度**（`gray`，转灰度后压缩）、**纯黑白**（`bw`，按阈值二值化，适合纯文字扫描件）、**保留颜色**（`color`，仅做压缩不改色彩）。
- 输出图片格式可选 **JPEG**（体积更小，可调质量）或 **PNG**（无损）；JPEG 质量、渲染 DPI、以及「先渲染再按百分比缩小」的下采样比例均可调。下采样只降低图像分辨率，输出 PDF 保持源页面尺寸。
- 支持一次添加多个 PDF 文件，或添加整个文件夹（递归查找其中的 `.pdf`）。
- 可自定义输出目录与输出文件名后缀；不指定输出目录时，结果与源文件放在同一位置，默认后缀分别为 `_压缩`（界面）和 `_cmp`（命令行）。写入同一输出目录时，如果多个源文件会产生同名输出，会自动追加短摘要以避免覆盖。
- 图形界面在后台线程中处理，带进度条、状态文字与日志区，并提供「停止」按钮。
- 命令行模式支持批处理并逐行打印进度，适合脚本或批量场景调用。

## 环境要求

- Python 3.8 或更高版本（代码使用 `from __future__ import annotations` 与 `list[Path]`、`Path | None` 等类型标注，在 3.8+ 下均可正常导入）。
- 第三方依赖：`PyMuPDF`、`Pillow`。
- 标准库依赖：`tkinter`、`argparse`、`threading`、`queue`、`io`、`pathlib`。

本项目目录内没有 `requirements.txt`，请手动安装依赖：

```bat
pip install pymupdf pillow
```

脚本在导入时会检查上述两个依赖，缺失时会在控制台直接提示对应的安装命令并退出。

## 使用方式

### 方式一：从源码运行

```bat
pip install pymupdf pillow
python PDF压缩工具.py
```

不带参数运行会直接打开图形界面。界面中依次：添加 PDF 文件或文件夹 → 选择模式与参数 → 设置输出目录和后缀 → 点击「开始转换」。

也可以在命令行模式下批量处理（提供 `--input` 时自动进入命令行模式）：

```bat
python PDF压缩工具.py -i "D:\扫描件" -o "D:\压缩输出" --mode gray --dpi 200 --quality 75

python PDF压缩工具.py -i a.pdf b.pdf --mode bw --threshold 180 --png

python PDF压缩工具.py --no-gui -i "D:\扫描件" --mode color --downscale 80
```

主要命令行参数：

| 参数 | 说明 |
|---|---|
| `-i, --input` | 要处理的文件或文件夹，可跟多个 |
| `-o, --out` | 输出目录，省略则输出到源文件旁 |
| `-s, --suffix` | 输出文件名后缀，默认 `_cmp` |
| `--mode` | `gray` / `bw` / `color`，默认 `gray` |
| `--threshold` | 二值化阈值 0–255，仅 `bw` 模式有效，默认 180 |
| `--dpi` | 渲染分辨率 72–1200，默认 200 |
| `--jpeg` / `--png` | 输出用 JPEG 还是 PNG，默认 JPEG |
| `--quality` | JPEG 质量 30–95，默认 75 |
| `--downscale` | 下采样百分比 50–100，默认 100 |
| `--no-gui` | 不启动界面，强制命令行模式 |

| 文件 | 说明 |

| `PDF压缩工具.py` | 唯一的源码文件，同时包含图形界面（`run_gui`）、命令行入口（`main`）和核心转换函数（`convert_pdf`）。 |

## 使用提示

- 三种模式都是「**整页渲染为位图后重新嵌入**」，因此输出 PDF 中的文字会变成图像，不再可选中、检索或复制，请保留原始文件备查。
- `bw` 模式下阈值滑杆才可用；`gray` / `color` 模式下 JPEG 质量滑杆才生效，界面会随模式自动启用或禁用相关控件。
- DPI 需为 72–1200 之间的整数；超出范围时界面会提示错误，命令行会拒绝该参数。默认值为 200，文字发虚时可提高到 300 或 400（同时文件会变大、耗时增加）。
- 点击「停止」后，当前正在处理的文件会先处理完，再从下一个文件开始停止。
